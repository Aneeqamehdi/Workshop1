Animal Care Notebook

This is a simple Animal Care Notebook application made with HTML, CSS and JavaScript.

Functions
Add an animal name, species and care note.

Validate the animal form before saving.

Show error messages for incorrect or empty fields.

Calculate animal sponsorship costs.

Give a 20% discount for sponsorships longer than 2 years.

Give an extra €5 discount for sponsorships of 5 years or more.

Save animal information using localStorage.

Automatically load the saved animal when the page opens.

Load saved animal information using the Load animal button.

Clear saved animal information using the Clear saved animal button.

Use sessionStorage to test temporary browser storage.
